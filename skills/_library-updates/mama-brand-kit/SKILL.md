# Mama Brand Kit

One skill. One source of truth. Every printed card, tent card, social graphic, and Canva post
pulls its colors, tagline, and footer from here — never from memory, never from a prior event.

---

## How to Use This Skill

**At the start of any material-building task:**
1. Read this skill.
2. Check whether an Active Brand is confirmed for the current event.
3. If yes — apply it. Do not ask Mama to repeat colors or taglines she's already provided.
4. If no — ask Mama to confirm the brand using the Brand Confirmation Prompt below.
5. Never carry forward branding from a previous event. FBU colors do not automatically apply
   to the next VFW event. Each event gets its own confirmed brand.

**When Mama says "set the brand" or "update branding":**
Present the Brand Confirmation Prompt, collect answers, store as the Active Brand for this thread.

## Rules for Downstream Skills

When any skill produces a printed or visual material, it must:

1. **Read mama-brand-kit first.** If no Active Brand is set, run the Brand Confirmation Prompt
   before touching any design work.
2. **Never hardcode colors or text** from a prior event. No FBU navy defaults appearing on
   a November VFW dinner program.
3. **Use hex codes without the # prefix** in docx generation scripts (e.g., `'1A2744'` not
   `'#1A2744'`) — this is a docx-js rendering requirement.
4. **Confirm logo status** before placing any emblem. Cleared means Mama or the authorized
   officer said yes in this thread — not assumed from a prior thread.
5. **Attribution footer always uses the confirmed format** — never improvise a footer.

sheets of coated inkjet cardstock.

## Notes on Color Selection (When Mama Doesn't Have Hex Codes)

If Mama describes a color without a hex code, suggest one from this reference and confirm:

| Description | Suggested Hex | Note |
|-------------|--------------|------|
| Navy blue | #1A2744 | Matches VFW Aux 969 established palette |
| Patriot red | #B22222 | Firebrick — prints well on Epson dye ink |
| Gold / star accent | #D4AF37 | Antique gold — readable on navy |
| Cream / off-white | #F5F0E8 | Warm cream — better than pure white on cardstock |
| Forest green | #2D5016 | For nature/homeschool events |
| Aviation blue | #2C4A6B | Use the Runways n Poppies Auxiliary Navy — do not invent a new aviation blue |
| Soft gray | #6B7280 | Body text on light backgrounds |

Always show the hex code to Mama and ask for confirmation before locking it in. Colors look
different on screen vs. printed on coated cardstock (dye ink prints 10-15% darker).
