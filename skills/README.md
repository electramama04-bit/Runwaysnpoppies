# Runways n Poppies skills

Skills for this brand, built to Mama's skill-builder rules: one skill, one job, brand
prefix plus a one-word suffix, companions named in every description.

| Skill | Its one job | Status |
|-------|-------------|--------|
| `rnp-reel-hooks` | The first two seconds of a video. Formulas, swipe file, the don'ts. | Built |
| `rnp-film-day` | What to capture on a field trip so the Reel exists. | Built |
| `rnp-content-calendar` | The Sunday planning session and the weekly rotation. | Built |
| `rnp-website-publishing` | Adding a document or link to runwaysnpoppies.com. | Proposed |

Pending edits to existing skills:

- **viral-hooks** — name `rnp-reel-hooks` as a companion so the general library and the

## Installing

Each skill folder zips on its own. `npm run skills` rebuilds every zip into `dist/`, which
is gitignored. Upload the zip and save it.
