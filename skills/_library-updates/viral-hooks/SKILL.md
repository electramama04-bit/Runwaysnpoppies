# Viral Hooks

The hook is the first 5 seconds of any post or video. It decides whether the reader stops
or scrolls. If you can hold 50% retention through the first 6 seconds of a short-form video,
it has a real shot at going viral. The hook carries that weight, so it gets written first
and rewritten until it earns the read.

The full 100-hook library (13 categories, examples) is in `references/hook-library.md`.
Read it at Step 2 below — don't load it before you have the topic and angle.

## When to Activate

- "Give me a hook for [topic]"
- "Write hook options for my [platform] post"
- "My opening line is weak — fix it"
- "What should the first line of this video be?"
- Whenever **vfw-969-social-captions** needs the hook line for a Long-form caption.
- When **rnp-reel-hooks** has no filled hook for a new Runways n Poppies trip and needs a
  template from the library to build one.

**If the post is for Runways n Poppies, use rnp-reel-hooks instead.** It carries 40 hooks
already filled with real aviation specifics, the eight short-form retention formulas, and
that brand's family facts. Come back here only for a category template it does not cover.

## Workflow

### Step 1: Get the topic and the angle

You need two things before picking a hook:

1. **The topic** — what the post is about.
2. **The angle** — a strong opinion, a specific number, a customer story, a mistake people
   make, or a result earned. This decides the category. If a `brand-brief.md` exists in the
   working folder, read its Strong Opinion / Wedge section — that fuels the highest-ceiling
   categories (Contrarian, Negative Frame).

If the topic is missing, ask. Do not invent a topic.

### Step 2: Pick a category

Read `references/hook-library.md` and match the angle to a category using its selection
table. When in doubt, prefer **The Receipt**, **Contrarian**, or **Stolen Lessons** — highest
virality ceiling.

### Step 3: Fill in 3 variations

Pick 3 templates from the library (one category or across two), and fill the placeholders
with real specifics from the topic. Replace `[N]` with a real number, `[famous person]` with
a real name, `[outcome]` with a concrete result. Generic fills kill the hook.

### Step 4: Run the first-3-words test

Read the first 3 words of each variation alone. Do they create curiosity, surprise, or
emotional pull?

- "Here's what I" → fail (no pull)
- "I tested 47" → pass (number + open loop)
- "Most people think" → pass (sets up a fight)

Cut filler from the front. The strongest word goes first.

### Step 5: Return the best one

Return the strongest variation, name the category, and offer the other 2 as alternates. If
called by another skill (e.g. vfw-969-social-captions), hand back all 3 so it can choose.

## Hook-Writing Rules

Apply these to every hook before returning it:

- **Specific beats abstract.** "I tested 47 scents" beats "I tested many scents."
- **First word is the strongest word.** Lead with the number, name, or surprise. Cut "so,"
  "okay," "today I want to talk about."
- **Could it stand alone as a tweet?** If it only makes sense with the body, it's too weak.
- **No filler.** Cut "really," "very," "just," "actually," "basically."
- **No generic AI openers.** Never "In today's fast-paced world," "Let me tell you," "Are you
  ready to," or "Picture this."
- **One hook, one idea.** Do not stack two hooks. Pick the strongest.

## What NOT to Do

- Don't return a hook with placeholders left unfilled. Fill every `[bracket]` with a real specific.
- Don't dump the whole library on the user. Return 1 strong hook plus 2 alternates.
- Don't pick a generic category (Listicle, Question) when the topic has a strong opinion or a
  real number — those map to higher-ceiling categories (Contrarian, Receipt).
- Don't reuse the same category for every post in a batch. Vary the patterns so a feed of
  posts doesn't read as formulaic.
