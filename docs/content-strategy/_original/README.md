August 25, 2026. It arrived named `.docx` but its contents are Markdown, so it is stored
here with the correct extension.

and nothing else:

   anywhere in this repo.
2. **Hook 38 was rewritten.** It was built entirely on the old name, so replacing the name
   would have left a broken sentence. The replacement keeps the same formula and the same
   idea.

Everything else is untouched. Where the archive and the organized files in the parent
folder disagree on anything, the parent folder is right.
