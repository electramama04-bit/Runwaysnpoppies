# Updates to existing library skills

These are **not** Runways n Poppies skills. They are edited copies of two skills that
already live in Mama's library, packaged here so the updated versions can be saved over
the originals.

| Skill | What changed |
|-------|--------------|
| `mama-brand-kit` | Added the Runways n Poppies standing brand block — full Master Plan v6 palette, the three-color rule, fonts, name spelling, the retired pre-launch name, platform and Blotato status. Marked the FBU Facebook page inactive. Pointed the "aviation blue" suggestion at the real Navy instead of an invented hex. Named both standing brands in the description so it triggers on either. |
| `viral-hooks` | Cross-referenced `rnp-reel-hooks` in the description and the activation list, with a plain instruction: if the post is for Runways n Poppies, use that skill instead, and come back here only for a category template it does not carry. |

## A note on size

`mama-brand-kit` is now 250 lines, which is the hard limit in mama-skill-builder for a
combined skill. It was already at 209 before this edit. If another standing brand gets
added it will need a split — the natural line is the confirmation prompt and rules in one
skill, the stored brand records in another.

## Saving these

Each folder zips on its own via `npm run skills` from the repo root. Save each over the
existing skill of the same name. Nothing else in the library changes.
